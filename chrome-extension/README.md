# JJKC Algorithm Viewer (Chrome Extension)

JJKC 사이트에 저장된 내 알고리즘 프로필을 받아와, **지금 보고 있는 유튜브 영상이 내 알고리즘과 얼마나 비슷한지**를 점수로 보여주는 크롬 확장 프로그램입니다. 추가로 JJKC 서비스에 대한 익명 만족도 리뷰를 사이트 DB에 저장할 수 있습니다.

확장 프로그램 팝업은 **`내 프로필`** 탭과 **`영상 유사도`** 탭으로 나뉘며, 하단에는 **만족도 평가** 영역이 있습니다.

---

## 설치

1. ZIP 압축 해제 (또는 이 폴더 준비)
2. `config.js`를 열고 OpenAI API 키를 입력-(현재는 테스트용 OpenAI API 키가 적용되어 있어 바로 사용 가능합니다.)
   ```js
   OPENAI_API_KEY: "PASTE_YOUR_OPENAI_API_KEY_HERE"
   ```
3. 크롬 주소창에 `chrome://extensions` 입력
4. 우측 상단 **개발자 모드 ON**
5. **압축해제된 확장 프로그램 로드** 클릭
6. 이 폴더 선택
7. JJKC Dashboard에서 Chrome Extension 연결 (아래 "기능 1" 참고)

---

## 기능 1. JJKC 프로필 연결

확장 프로그램이 내 알고리즘을 비교하려면 먼저 JJKC 사용자 ID를 확장 프로그램에 저장해야 합니다. 두 가지 방법이 있습니다.

### 1-A. Dashboard 자동 연동 (브리지)

1. 사용자가 JJKC 사이트(`jjkc-algo-blush.vercel.app`)에 로그인한다.
2. 사이트가 `window.postMessage`로 `{ type: "JJKC_CONNECT_EXTENSION", userId }` 메시지를 보낸다.
3. 확장 프로그램의 `content.js`가 이 메시지를 수신하고, **허용된 출처(origin)인지** 검증한다.
4. 검증을 통과하면 `userId`를 `chrome.storage.local`에 저장한다.
5. 저장이 끝나면 사이트로 `{ type: "JJKC_CONNECT_EXTENSION_DONE", ok: true }` 응답을 돌려보내 연동 완료를 알린다.

### 1-B. 수동 연결

1. 팝업의 `내 프로필` 탭에서 입력창에 **User ID**를 직접 입력한다.
2. **수동 연결** 버튼을 누른다.
3. 입력값이 비어 있으면 "사용자 ID를 입력하세요" 오류를 표시한다.
4. 값이 있으면 `chrome.storage.local`에 `jjkcUserId`로 저장한다.
5. 곧바로 프로필을 다시 불러온다(기능 2).

### 연결 해제

1. **연결 해제** 버튼을 누른다.
2. `chrome.storage.local`에서 `jjkcUserId`를 삭제한다.
3. 입력창을 비우고 "연결이 해제되었습니다" 메시지를 표시한다.

## 기능 2. 내 프로필 표시

저장된 사용자 ID로 사이트에서 내 알고리즘 요약을 받아와 보여줍니다.

1. `chrome.storage.local`에서 `jjkcUserId`를 읽는다. 없으면 "아직 연결되지 않았습니다"를 표시하고 종료한다.
2. `GET /api/profile/{userId}`를 호출해 프로필 데이터를 받는다.
3. 응답에서 **카테고리 점수**, **Top 채널**, **요약 텍스트**를 추출한다.
4. 카테고리 점수를 17개 JJKC 표준 카테고리 벡터로 정규화한다(합계 100% 기준).
5. 정규화된 벡터에서 상위 5개 카테고리를 골라 비중(%)과 함께 칩으로 표시한다.
6. Top 채널(최대 5개)과 알고리즘 요약 문구를 함께 표시한다.
7. 호출이 실패하면 "프로필을 불러오지 못했습니다" 오류와 점검 안내를 표시한다.

## 기능 4. 현재 유튜브 영상 분석 (영상 유사도)

`영상 유사도` 탭으로 이동하거나 **현재 영상 유사도 분석** 버튼을 누르면 실행됩니다. 현재 보고 있는 유튜브 영상의 성향을 추정하고, 내 알고리즘과의 유사도를 계산합니다.

### 4-1. 사전 조건 확인

1. 현재 활성 탭을 조회한다.
2. 탭 URL이 `youtube.com`이 아니면 "YouTube 페이지에서만 사용할 수 있습니다" 오류를 표시하고 종료한다.
3. 내 프로필을 불러온다. 사용자 ID가 없으면 "먼저 JJKC 프로필을 연결해야 합니다" 안내를 표시하고 종료한다.

### 4-2. 현재 영상 정보 수집 (content.js)

1. 팝업이 content script로 `{ type: "JJKC_ANALYZE_CURRENT_VIDEO" }` 메시지를 보낸다.
2. content script는 유튜브 내부 라우팅(새로고침 없이 영상이 바뀌는 경우)을 고려해, **현재 URL의 videoId와 DOM이 일치할 때까지** 최대 약 2.6초 대기한다.
3. DOM과 `ytInitialPlayerResponse`에서 다음을 수집한다.
   - 제목, 채널명, videoId
   - 공식 카테고리, 메타데이터 키워드
   - 영상 설명 스니펫과 해시태그
   - 제목·채널·설명에서 추출한 일반 키워드
4. 수집한 영상 정보 객체를 팝업으로 응답한다.

### 4-3. LLM 카테고리 분류 (popup.js → OpenAI)

1. `config.js`에 OpenAI API 키가 설정되어 있는지 확인한다. (없으면 이 단계를 건너뛰고 4-4의 DOM fallback으로 진행)
2. 수집한 영상 정보(제목·채널·설명·해시태그·키워드·공식 카테고리)로 분류용 프롬프트를 만든다.
3. OpenAI `/v1/responses` API를 **JSON Schema strict 모드**로 호출한다. 모델은 영상을 17개 JJKC 카테고리에 **합계 100%**로 분배하고, 키워드·해시태그·한국어 요약·신뢰도를 함께 반환한다.
4. 응답 JSON을 파싱해 카테고리 점수를 표준 벡터로 정규화하고, LLM 키워드를 DOM 키워드와 합친다.
5. LLM 호출이 실패하면 `null`을 반환한다.

### 4-4. 분석 출처 결정 (Fallback)

- LLM 결과가 있으면 → **"OpenAI LLM 기반 태그 추정"** 으로 사용한다.
- LLM 결과가 없으면 → content.js가 **사전(lexicon) 기반 + 공식 카테고리 가중치**로 계산한 DOM 점수를 사용하고, "DOM fallback 분석"으로 표시한다.

### 4-5. 유사도 계산 (하이브리드)

내 카테고리 벡터와 영상 카테고리 벡터를 비교해 3가지 점수를 합산합니다.

1. **기본 카테고리 유사도 (cosine, 가중치 40%)** — 두 벡터의 코사인 유사도.
2. **관련 카테고리 보정 (affinity, 가중치 40%)** — 카테고리가 정확히 같지 않아도 관련도(예: 과학·기술 ↔ 교육)가 있으면 점수를 부여한다.
3. **키워드 보정 (keyword, 가중치 20%)** — 영상 키워드·해시태그가 내 프로필 텍스트(요약·채널·상위 카테고리)와 겹치는 정도. 해시태그는 일반 키워드보다 1.5배 강하게 반영하고, `1 - exp(-x/3)` 곡선으로 완만하게 상승시킨다.
4. 세 점수를 가중 합산한 raw 값(0~1)을 `5 + sqrt(raw) * 95` 로 스케일링해 **최종 유사도(5~100%)** 를 만든다.
5. 점수 구간에 따라 유사 수준(매우 높음/높음/보통/낮음/매우 낮음)과 코멘트를 생성한다.

### 4-6. 결과 표시

1. 현재 영상 제목·채널·분석 출처·분류 신뢰도(있으면 LLM 요약)를 표시한다.
2. 최종 유사도 점수와 진행 바, 유사 수준, 코멘트를 표시한다.
3. 점수 분해(기본 카테고리 / 관련 카테고리 / 키워드 보정)를 항목별로 보여준다.
4. 영상 추정 카테고리 Top 5와 내 주요 카테고리 Top 5를 미니 막대로 나란히 표시한다.
5. 영상/채널 키워드와 영상 설명 해시태그를 칩으로 표시한다.

## 기능 5. JJKC 서비스 만족도 평가 (익명 리뷰)

팝업 하단에서 서비스 만족도를 익명으로 제출합니다.

1. **별점(1~5)** 을 선택하고 **리뷰 내용**을 입력한다.
2. **익명 리뷰 제출** 버튼을 누른다.
3. 입력값을 검증한다.
   - 별점이 1~5 정수가 아니면 "별점을 선택해주세요"
   - 내용이 비어 있으면 "리뷰 내용을 입력해주세요"
   - 내용이 500자를 초과하면 "리뷰는 500자 이하로 입력해주세요"
4. 검증을 통과하면 "익명 리뷰를 저장하는 중..." 을 표시한다.
5. `POST /api/extension/reviews` 로 `{ rating, reviewText }` 만 전송한다. (사용자 ID 등 개인 식별 정보는 보내지 않음 → 익명)
6. 성공하면 입력창을 비우고 "익명 리뷰가 저장되었습니다" 를 표시한다.
7. 실패하면 "리뷰 저장 중 오류가 발생했습니다" 와 API 배포 상태 점검 안내를 표시한다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 프로그램 설정(권한, 호스트, content script 등록) |
| `popup.html` | 팝업 UI 구조(탭, 프로필, 영상 유사도, 리뷰) |
| `popup.js` | 프로필 로드, LLM 호출, 유사도 계산, 리뷰 제출 등 핵심 로직 |
| `content.js` | 유튜브 DOM에서 영상 정보 수집, 사이트 연동 브리지 메시지 처리 |
| `config.js` | OpenAI API 키·모델 설정 |
