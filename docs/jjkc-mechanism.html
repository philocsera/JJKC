Phase 1
Building the Algorithm Profile (알고리즘 프로필 구축)
Three input methods — and why Methods 1 & 2 alone aren't enough. (세 가지 입력 방법, 그리고 1·2만으로는 부족한 이유.)
1Google Sign-in (Google 로그인)
＋One click, instant analysis from real subscription data. (클릭 한 번, 실제 구독 데이터로 즉시 분석.)
－Needs API permission + a daily quota — can't scale, and users hesitate at OAuth. (API 권한·일일 쿼터 필요 — 확장 불가, OAuth에서 이탈.)
2Takeout JSON Upload (Takeout 업로드)
＋No permission or quota — analyzes the entire watch history. (권한·쿼터 없이 전체 시청기록 분석.)
－Request → email → ZIP → unzip → upload: ~30 min, most users drop off. (요청→메일→ZIP→해제→업로드: ~30분, 대부분 이탈.)
Why we added Method 3 (방법 3을 추가한 이유)
M1 is easy but not viable; M2 is powerful but hard to reach. Method 3 fills the gap — no login, no file, no waiting. (M1은 쉽지만 비현실적, M2는 강력하지만 도달이 어려움. 방법 3이 그 빈틈을 메움 — 로그인·파일·대기 없음.)
Accessibility × Depth (접근성 × 깊이)
